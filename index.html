Cumulative Flow Diagram (CFD)

Tracks issue counts by state over time. Ideal for identifying queues and WIP bloat.

WIP Run Chart

Tracks active WIP day by day to show flow stability over time.

Cycle Time Control Chart

Scatterplot of completed items over time. Each slice gets its own 50% (dotted) and 85% SLE (dashed) lines in the slice color, so you can set a different SLE per slice.

Work Item Age Chart (Active WIP)

Scatterplot of active, unfinished items and how many days they've been in progress. Leading indicator for SLA breaches.

Flow Distribution

Stacked bar chart of items completed per week, broken down by selected category.

Defect Trend EXPERIMENTAL

Failure-demand (rework/defect) items created over time — an EBM Ability-to-Innovate signal. A rising slope means quality is eroding and rework is crowding out new value.

Value Delivery Curve EXPERIMENTAL

Cumulative value delivered, actual sequencing vs. an ideal value-first sequence. Uses Cost of Delay if present, else Priority, else backlog Rank, else FIFO arrival order.

Sprint Predictability & Carryover

Bar chart of items planned for the sprint vs completed in the sprint. Reference lines show 85% & 50% confidence based on completed items, with standard deviation shaded.

Estimation vs Actual Cycle Time

Scatter plot analyzing the correlation between estimated size and actual delivery time.

Sprint Comet Chart

Visualizes cycle times and status transitions of issues within sprints.
